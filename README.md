# real-life-patch-notes

Entry for make.fun bounty "Real-Life Patch Notes: The Comedy Changelog"
(`u-0xb3e689-real-life-patch-notes-the-comedy-changelog-c5844c1d`).

`main.py` writes one patch-note line — a fix for the eye-floaters bug — to
`/output/entry.txt`:

> v1.4.7: fixed a bug where the eyes rendered a tiny transparent worm that follows the user's gaze and dodges every attempt to look at it.

## Run it

```sh
python3 main.py
cat /output/entry.txt
```
